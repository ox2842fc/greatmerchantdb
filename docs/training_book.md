# 巨商修練書 (Gersang Training Book)

「巨商修練書」是為新手與回歸玩家設計的福利系統，旨在透過一系列引導任務幫助玩家快速熟悉遊戲系統並獲得強大獎勵。

!!! info "系統資訊"
    - **接取 NPC**：白商會會長_瑞來 (White Merchant Guild President Seorae)
    - **地點**：順天 (Suncheon) 附近
    - **條件**：信用等級達到 **70 或以上**
    - **限制**：每個角色僅能執行一次（共 30 個任務，必須依序完成）

## UI 介面開啟方式

!!! tip "快速開啟設定"
    1. 按下 `ESC` 鍵進入系統選單。
    2. 點擊「設定快選欄位」。
    3. 將「巨商修練書」圖示拖曳至最上方欄位。
    4. 確保勾選「快選顯示」。
    5. 在遊戲畫面右側的任務通知中，**按右鍵**即可開啟專屬 UI 介面。

## 核心獎勵說明

!!! success "重點回饋"
    - **第 25 關**：送一位 **覺醒將帥**（4選1），極大強化隊伍前期實力。
    - **第 29 關**：獲得 **「兇獸傳喚書」**（饕餮、混沌、窮奇、檮杌 4選1），這是目前遊戲中最頂級的福利之一。
    - **第 30 關**：獲得 **屬性套裝**，為後期的屬性戰鬥做好準備。
