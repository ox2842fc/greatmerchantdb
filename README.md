# Great Merchant DB

Welcome to the Great Merchant DB, a comprehensive database and guide for the game Great Merchant. This project is built using MkDocs and provides detailed information on various aspects of the game.

## Features

- Detailed guides on character awakenings, game systems, and raid strategies.
- A clean, readable, and responsive documentation site.
- Built with MkDocs and the Material for MkDocs theme.

## Installation and Setup

To set up the project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ox2842fc/greatmerchantdb.git
    cd greatmerchantdb
    ```

2.  **Install dependencies:**
    Make sure you have Python and pip installed. Then, install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the development server:**
    ```bash
    mkdocs serve
    ```
    The site will be available at `http://127.0.0.1:8000`.

## Usage

The documentation is organized into several sections, which you can navigate using the sidebar. The main sections include:

-   **主頁 (Home):** The main landing page.
-   **覺醒天王 (Awaken Devas):** Information about awakened characters.
-   **星宿系統 (Star System):** Details on the star system.
-   **雜項 (Tips):** Various tips and tricks.
-   **攻略 (Strategies):** Raid and other strategies.
-   **日誌 (History):** Project history and updates.
